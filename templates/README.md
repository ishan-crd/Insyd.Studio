# Templates

Launch-video templates that open in Studio by Insyd. Each folder is a standalone Remotion project with
the Studio SDK vendored in `src/insyd/`: open it from Studio's project screen, edit anything (copy,
logo, colours, timing, every sound), save — the edits are written into the template's source.

| Template | Length | Look |
|---|---|---|
| [`studio-launch`](studio-launch) | 58 s | Dark, glyph-rendered type, decode captions, a glowing orb, product reveal on a monitor — the Studio by Insyd launch film |

```
cd templates/<name> && npm install && npm run render
```
